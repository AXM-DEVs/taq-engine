Contenido claro

No es OSINT. No es un reemplazo de SIEM. No es una plataforma genérica más.

TaQ Engine es una capa programable de ejecución para inteligencia de amenazas: define flujos, conserva contexto y convierte decisiones en operaciones repetibles.

DefinidoModelado como código

Los flujos se escriben, versionan y revisan como un activo operativo, no como una colección de capturas.

TrazableAuditoría completa

Cada acción conserva origen, autor, versión y justificación para equipos con requisitos de gobernanza estrictos.

ÚtilLegible para analistas

La interfaz mantiene densidad suficiente para operar sin perder la claridad que necesitan los equipos humanos.

Playbooks que se leen como sistemas, no como diagramas decorativos.

La visualización interactiva expone pasos, dependencias y salida esperada. El usuario cambia de contexto sin cambiar de lenguaje.

Playbook seleccionadoTriage

Entra una señal, se normaliza, se correlaciona y se entrega una decisión auditada al equipo adecuado.

Puntos de controlGobierno

Versionado, aprobaciones, excepciones y retorno a estado anterior con evidencia visible para cada cambio.

SecuenciaFlujo

Conectores de entrada → normalización → scoring → decisión → registro. Cada transición conserva contexto.

SalidaAcción

Notificación al SOC, creación de caso, enriquecimiento posterior o cierre con trazabilidad completa.

Investigación guiada con una narrativa de operación continua.

El scroll cuenta la historia del trabajo: detectar, confirmar, enriquecer, decidir y conservar evidencia. Sin teatralidad, con precisión.

1

Señal inicial

La investigación parte de un evento, un lote de indicadores o un cambio de comportamiento que merece contexto.

2

Enriquecimiento

TaQ cruza fuentes, resuelve entidades y preserva el origen de cada dato para que la confianza sea explícita.

3

Decisión

El playbook propone la siguiente acción y muestra por qué la recomendación es consistente con el contexto.

4

Cierre auditable

El resultado queda registrado, versionado y listo para revisar o reutilizar en futuras investigaciones.
